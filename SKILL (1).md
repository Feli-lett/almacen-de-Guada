# 3D Web Experience Skill

This skill focuses on building interactive 3D graphics and immersive experiences directly in the browser.

## Typical Uses
- Setting up a Three.js scene with cameras, lights, and rendering.
- Importing and animating 3D models (GLTF/GLB).
- Creating complex shaders and particle systems.
- Integrating 3D elements smoothly with standard DOM elements.
- Optimizing 3D performance for web.

## How to Invoke
When you want to add 3D elements, ask the assistant to *use the `3d-web-experience` skill* and describe the scene or effect you want.

## Example Prompt
```
Set up a basic React Three Fiber scene with a rotating cube, ambient lighting, and orbit controls. Provide the code for both the 3D canvas and the containing HTML structure.
```

## Resources
- You can store `.glb` or `.gltf` model files in a `resources/models/` directory for the skill to reference.
- Store common shader code in `scripts/shaders/`.
